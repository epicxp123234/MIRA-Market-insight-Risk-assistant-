The learned directional experts consume engineered price features; the Bayesian, Kalman, GARCH and HMM outputs provide separately reported statistical context. Only components explicitly listed in the fusion weights influence the directional probability.

Calculation methods and equations
Log return: rₜ = ln(Pₜ / Pₜ₋₁); first / second differences track change and curvature in returns.
Bayesian drift: Normal prior + Normal return likelihood → posterior mean, variance and P(μ > 0).
Kalman: predict latent level/trend, calculate innovation, then update state with the Kalman gain.
GARCH(1,1): σ²ₜ₊₁ = ω + αε²ₜ + βσ²ₜ.
Gaussian HMM: Baum–Welch estimates emissions/transitions; forward filtering estimates next high-volatility state probability.
Logistic expert: reverse-mode AD gradient + exact Hessian; damped Newton step with line search minimizes regularized log-loss.

Paper trading (simulated money) · QQQ

OFF

When on, after each new day\'s close the model moves this Alpaca PAPER account to match its own call: BUY = invest your chosen % of paper equity in QQQ, SELL = go flat. Take-profit / stop-loss %, if set, are checked every 5 seconds while the market is open (every 60s otherwise) and sell automatically the instant either is hit, independent of the model\'s call - so a fast intraday move doesn\'t have to wait on the next daily call. No real money is ever involved; this only runs on your own computer, never from the public page.

Learning from wrong calls

Real numbers only, not invented reasoning

Each wrong call feeds into the next retraining (about every 21 trading days); a retrained version only replaces the current one if it proves better on unseen data. These are honest descriptions of what the numbers were on the day it got a call wrong, not the network explaining its own thinking - it can't do that, it only outputs a number.
